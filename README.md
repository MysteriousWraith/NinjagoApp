# Lego Ninjago UA Archive (v1.1 — Built-in Player + Рюкзак + Private TG Backend)

Фанатское Android-приложение (Kotlin + Jetpack Compose + Media3 ExoPlayer) с полностью украинским интерфейсом для просмотра классических сезонов **LEGO Ninjago (0–15 + спешлы и фильм)** в 1080p с украинским дубляжом **прямо внутри приложения**.

## Что нового в v1.1
- **Встроенный 1080p-видеоплеер (Media3 / ExoPlayer)** с поворотом экрана и автосохранением точного **таймкода** для карточки «Продовжити перегляд».
- **Офлайн-режим «Рюкзак»:** скачивание серий в закрытую память приложения (не светятся в галерее) + просмотр без интернета.
- **«Обране (Закладки)»** и **Поиск** по сезонам и сериям.
- **Убрана «Вітрина Наборів»** по запросу.
- **Папка `backend/`:** готовый бесплатный FastAPI + Telethon (MTProto) прокси-сервер для твоего приватного ТГ-канала (`-1004438841209`), где уже прописана `S00E01` («Шлях Ніндзя», `telegramMessageId = 3`). Подробная инструкция запуска за 0 грн/мес — в `backend/README.md`.
